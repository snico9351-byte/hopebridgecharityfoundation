# HopeBridge Foundation – Charity Website

A complete emotional charity website for helping orphans, widows and victims of war (focus on India, also Palestine, Haiti and other countries).

## Features

- Beautiful public website with emotional storytelling
- Language translator (English, Hindi, Arabic, Spanish, French, Portuguese, Indonesian + more)
- Donation form that collects **Name** and **Phone/WhatsApp number**
- Direct WhatsApp (+1 518 416 8768) and Email (franklinlewis@groupmail.com) contact
- Admin panel with password login
- One-click “Send Thank You” that opens WhatsApp with a personalised appreciation message

## How to use

### Public site
1. Open `index.html`
2. Visitors fill the donation form (name + phone)
3. They can also contact via WhatsApp or Email to request bank account details

### Admin panel
1. Open `admin.html`
2. Login with password: **hope2026** (change it inside `script.js`)
3. See all people who submitted the form
4. Edit the appreciation message template if you want
5. Click **Send Thank You** → WhatsApp opens with the message already written for that person → just press Send

## Important notes

- This is a **static** website (works on GitHub Pages, Netlify, etc.)
- Donation records are saved in the browser’s localStorage (demo only)
- For a real organisation you should later connect a real database and WhatsApp Business API
- Always verify donations manually before sending thank-you messages
